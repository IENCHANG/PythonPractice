# 定存複利計算器 (Compound Interest Calculator)

一個簡單的 Python 命令行程式，用於計算定期存款在指定年限後的本利和與總利息收入。

---

## 📌 功能特點

1. **本金輸入驗證**：確保輸入的存款本金金額大於 0。
2. **存款年限驗證**：確保輸入的存款年數大於 0（若輸入無效年限會有相應提示）。
3. **複利計算與格式化輸出**：
   - 自動計算指定年數後的**總本利和**。
   - 計算產生的**總利息**。
   - 輸出結果自動加上千分位符號（例如 `100,000`），方便閱讀。

---

## 🛠️ 使用技術

- **程式語言**：Python 3
- **控制結構**：`while` 迴圈輸入驗證
- **資料型態與格式化**：`int` 轉型、f-string 千分位格式化 (`:,`)

---

## 🚀 執行方式

1. 確保電腦已安裝 Python 3。
2. 將程式碼儲存為 `main.py` 或任意 `.py` 檔案。
3. 開啟終端機 (Terminal) 或命令提示字元 (CMD)，執行以下指令：

```bash
python main.py
```

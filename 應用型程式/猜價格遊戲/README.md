# 🎯 雙人商品價格猜測遊戲 (Guess the Price Game)

這是一個雙人對戰的 Python 命令列猜價格遊戲。兩位玩家透過輪流輸入價格，競逐誰能最快猜中正確價格，或在限定次數內猜出最接近的答案！

---

## 💡 功能特點

1. **雙人對決機制**：支援自訂兩位玩家暱稱，進行同台競技。
2. **回合限制**：每局遊戲最多進行 **3 次** 猜測機會。
3. **即時比對與提示**：
   - 若有玩家直接猜中正確價格，遊戲立即結束並宣判獲勝。
   - 若該輪未有人猜中，程式會計算絕對誤差（$\| \text{目標價格} - \text{玩家答案} \|$），提示哪一位玩家的答案比較接近。
4. **終局勝負判定**：
   - **完全猜中**：優先判定猜中價格者獲勝。
   - **回合耗盡**：若 3 次機會內皆未猜中，以最後一輪答案距離目標價格較近者獲勝，並公佈正確金額。

---

## 🛠️ 環境需求

- **Python 3.x** 或更高版本

---

## 🚀 使用說明與步驟

### 1. 執行程式
開啟終端機（Terminal）或命令提示字元（CMD），執行 Python 腳本：
```bash
python game.py
```

### 2. 設定暱稱
進入遊戲後，依序輸入第一位與第二位玩家的暱稱：
```text
請輸入第一位玩家的暱稱: 小明
請輸入第二位玩家的暱稱: 小華
```

### 3. 輸入猜測價格
每回合兩位玩家依序輸入心中的商品價格（限整數）：
```text
請小明輸入商品價格: 800
請小華輸入商品價格: 1200
```

---

## 📖 執行範例

### 範例一：直接猜中獲勝
```text
請輸入第一位玩家的暱稱: 小明
請輸入第二位玩家的暱稱: 小華
請小明輸入商品價格: 900
請小華輸入商品價格: 1000
小華猜對了!小華獲勝!
```

### 範例二：未完全猜中（3次回合後以接近度判定）
```text
請輸入第一位玩家的暱稱: Alice
請輸入第二位玩家的暱稱: Bob
請Alice輸入商品價格: 800
請Bob輸入商品價格: 1300
Alice的答案比較接近
請Alice輸入商品價格: 850
請Bob輸入商品價格: 1200
Alice的答案比較接近
請Alice輸入商品價格: 920
請Bob輸入商品價格: 1100
Bob的答案比較接近
遊戲結束!正確的商品價格是1000，Bob的答案比較接近，Bob獲勝!
```

---

## ⚙️ 變數設定與邏輯

- **`商品價格`**：預設為 `1000`（可於程式碼第一行修改目標金額）。
- **`總次數`**：預設為 `3` 次猜測機會。
- **`abs()` 絕對值函數**：用於計算玩家答案與目標價格的距離（如 `abs(1000 - 800) = 200`）。

# 三角形判斷程式 (Triangle Classifier)

這是一個簡單的 Python 程式，用於讀取三個整數並進行以下處理：
1. 將三個整數由小到大排序。
2. 判斷這三個邊長是否能構成三角形。
3. 若能構成三角形，進一步判斷其類型（直角三角形、銳角三角形或鈍角三角形）。

---

## 程式碼內容

```python
a, b, c = map(int, input().split())

# 將三個數值由小到大排序 (Bubble Sort 思路)
if a > b:
    a, b = b, a
if b > c:
    b, c = c, b
if a > b:
    a, b = b, a

# 印出排序後的邊長
print(a, b, c)

# 判斷三角形類型
if a + b <= c:
    print("NO")          # 無法構成三角形
elif a**2 + b**2 == c**2:
    print("Right")       # 直角三角形
elif a**2 + b**2 > c**2:
    print("Acute")       # 銳角三角形
elif a**2 + b**2 < c**2:
    print("Obtuse")      # 鈍角三角形
```

> **注意：** 在原始程式碼中，`a^2` 為 Python 的按位異或（XOR）運算子。上述範例修正為 `a**2`（次方運算）以符合數學判斷邏輯。

---

## 輸入與輸出說明

### 輸入格式
輸入為一行，包含三個以空格分隔的整數 $a, b, c$。

### 輸出格式
1. 第一行：輸出排序後的三個整數，中間以空格分隔。
2. 第二行：輸出三角形的判斷結果：
   - `NO`：兩邊之和不大於第三邊，無法構成三角形。
   - `Right`：符合畢氏定理 $a^2 + b^2 = c^2$，為直角三角形。
   - `Acute`：符合 $a^2 + b^2 > c^2$，為銳角三角形。
   - `Obtuse`：符合 $a^2 + b^2 < c^2$，為鈍角三角形。

---

## 範例測試

### 範例 1
**輸入：**
```
4 3 5
```
**輸出：**
```
3 4 5
Right
```

### 範例 2
**輸入：**
```
1 1 2
```
**輸出：**
```
1 1 2
NO
```

## 使用方法

1. 安裝 [Python 3](https://www.python.org/)。
2. 將程式碼儲存為 `triangle.py`。
3. 在終端機或命令提示字元執行：
   ```bash
   python triangle.py
   ```
4. 輸入三個整數並按下 Enter 查看結果。

# 學生成績查詢與登記系統 (Student Grade Management System)

這是一個基於 Python 開發的互動式命令列學生成績查詢與登記系統 [cite: 1]。本系統模擬教師向導師索取學生各科成績單，並處理後續成績修正通知的情境 [cite: 1]。

---

## 📌 系統功能特色

1. **學生類別與成績封裝**：
   - 使用物件導向程式設計（OOP）建立基礎 `Student` 類別及其衍生類別（`Student1`, `Student2`, `Student3`），管理學生成績資料（包含英文、中文、數學、歷史、地理、公民）[cite: 1]。
2. **教師身份與權限驗證**：
   - 互動式詢問教師身份（如社會科老師、導師等）並進行對應回應 [cite: 1]。
3. **成績單查詢與輸出**：
   - 提供互動式選項向導師索取完整的學生成績登記表 [cite: 1]。
4. **成績修正事件處置**：
   - 模擬收到訊息通知「數學成績登記錯誤」，由使用者選擇是否進行加分修正 (+5 分) [cite: 1]。

---

## 🛠️ 類別結構說明

### `Student` (基礎類別)
- **屬性**：
  - `name`: 學生姓名 [cite: 1]
  - `grade`: 年級 [cite: 1]
- **方法**：
  - `introduce()`: 印出學生姓名與年級 [cite: 1]

### `Student1` / `Student2` / `Student3` (繼承自 `Student`)
- **延伸屬性**：
  - `Etest`: 英文成績 [cite: 1]
  - `Ctest`: 中文成績 [cite: 1]
  - `Mtest`: 數學成績 [cite: 1]
  - `Htest`: 歷史成績 [cite: 1]
  - `地test`: 地理成績 [cite: 1]
  - `公test`: 公民成績 [cite: 1]

## 🚀 執行方式

1. 確保電腦已安裝 **Python 3.x** [cite: 1]。
2. 將程式碼儲存為 `main.py` [cite: 1]。
3. 開啟終端機 (Terminal) 或命令提示字元 (CMD)，執行以下指令：

```bash
python main.py
```

## 📋 使用流程與互動範例

### 1. 教師身分確認
執行程式後，系統會詢問：
```text
您是什麼科的老師？
```
- 輸入 `社會`：顯示 `ok,收到` 並進入下一階段 [cite: 1]。
- 輸入 `導師`：顯示 `呃，請重新輸入` [cite: 1]。
- 輸入其他任一內容：離開身分確認階段 [cite: 1]。

### 2. 成績單索取
系統會詢問：
```text
現在成績在導師手上，請問您要向導師索取嗎？
```
- 輸入 `yes`：印出周挽、陸西驍、姜彥等三位學生的各科成績單 [cite: 1]。
- 輸入 `no`：顯示 `已離開!!` [cite: 1]。

### 3. 數學成績修正通知
系統顯示收到 Line 訊息：
```text
Line 一則訊息 5s前
老師，不好意思，數學老師登記錯誤了，還請老師幫忙改正一下
要不要幫忙改一下?
```
- 輸入 `好`：重新輸出成績表，並於數學成績後標示 `+5` [cite: 1]。
- 輸入 `不要` 或 `no`：系統給予回覆並結束流程 [cite: 1]。

# 基礎整數計算器 (Basic Integer Calculator)

這是一個簡單且直觀的 Python 命令列計算器工具，支援基礎的整數加、減、乘、除運算。

---

## 💡 功能特點

1. **基本四則運算**：
   - ➕ **加法** (`+`)
   - ➖ **減法** (`-`)
   - ✖️ **乘法** (`*`)
   - ➗ **除法** (`//` 與 `%`)：自動計算整數商數與餘數。
2. **智慧除法輸出**：
   - 若能整除，僅顯示商數（例如：`6 除 2 等於 3`）。
   - 若有餘數，會完整顯示商數與餘數（例如：`7 除 2 等於 3 餘 1`）。
3. **持續互動介面**：使用 `while` 迴圈提供選單，可連續進行多筆計算，直到使用者主動退出。

---

## 🛠️ 環境需求

- **Python 3.x** 或更高版本

---

## 🚀 使用說明與步驟

### 1. 執行程式
開啟終端機（Terminal）或命令提示字元（CMD），並執行 Python 腳本：
```bash
python calculator.py
```

### 2. 選項介面
執行後將會看到提示訊息：
```text
請輸入計算類型(1)加(2)減(3)乘(4)除(或按任意鍵關閉):
```

- 輸入 `1`：執行加法
- 輸入 `2`：執行減法
- 輸入 `3`：執行乘法
- 輸入 `4`：執行除法
- **輸入其他任意鍵**：結束程式（顯示 `see you next time ~`）

### 3. 輸入數字
選擇計算類型後，依提示輸入兩個整數：
```text
請輸入第一個整數: 10
請輸入第二個整數: 3
```

---

## 📖 執行範例

### 範例一：加法運算
```text
請輸入計算類型(1)加(2)減(3)乘(4)除(或按任意鍵關閉): 1
請輸入第一個整數: 15
請輸入第二個整數: 25
15 加 25 等於 40
```

### 範例二：除法運算（有餘數）
```text
請輸入計算類型(1)加(2)減(3)乘(4)除(或按任意鍵關閉): 4
請輸入第一個整數: 10
請輸入第二個整數: 3
10 除 3 等於 3 餘 1
```

### 範例三：退出程式
```text
請輸入計算類型(1)加(2)減(3)乘(4)除(或按任意鍵關閉): q
see you next time ~
```

## 📝 函式說明

| 函式名稱 | 傳入參數 | 回傳值 | 說明 |
| :--- | :--- | :--- | :--- |
| `加法(x, y)` | `x`, `y` (整數) | `x + y` | 計算兩數之和 |
| `減法(x, y)` | `x`, `y` (整數) | `x - y` | 計算兩數之差 |
| `乘法(x, y)` | `x`, `y` (整數) | `x * y` | 計算兩數之積 |
| `除法(x, y)` | `x`, `y` (整數) | `(商數, 餘數)` | 回傳包含 `商數` 與 `餘數` 的元組 (Tuple) |

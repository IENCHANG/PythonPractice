本金複利試算機 (Compound Interest Calculator)這是一個基於 Python 撰寫的終端機互動式複利試算小工具。使用者可輸入預計存入的本金與存款年數，系統會自動計算出期滿後的資產總額以及累積獲得的總利息。📌 功能特色 (Features)輸入驗證與防呆機制：使用 while 迴圈確保輸入的「本金」與「存款年限」為有效正整數（大於 0）。若輸入小於等於 0 的不合規數字，系統會提供互動提示並要求重新輸入。複利數學運算：採用標準複利公式計算總資產與利息：$$\text{Total} = \text{本金} \times \left(1 + \frac{\text{年利率}}{100}\right)^{\text{存款年數}}$$金額千分位格式化顯示：輸出最終獲得的總金額與利息時，自動加上千分位分隔符號（例如 100,000 元），提升數據閱讀舒適度。🛠️ 程式邏輯說明 (Program Logic)程式碼片段flowchart TD
    A[開始] --> B{輸入本金 > 0 ?}
    B -- 否 --> B
    B -- 是 --> C{輸入存款年數 > 0 ?}
    C -- 否 (提示錯誤) --> C
    C -- 是 --> D[計算複利總金額與利息]
    D --> E[使用千分位格式化輸出結果]
    E --> F[結束]

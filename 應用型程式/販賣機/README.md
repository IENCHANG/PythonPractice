# 簡易販賣機 / 點餐系統 (Vending Machine CLI)

這是一個使用 Python 撰寫的命令列介面（CLI）販賣機點餐系統。使用者可以瀏覽菜單、重複選擇餐點並進行金額累加，最後輸出總金額進行結帳。

---

## 📌 功能特色

* **菜單展示**：自動列出所有可供選擇的餐點及其價格。
* **動態點餐**：採用迴圈機制，可連續輸入品項。
* **錯誤處理**：若輸入不在菜單上的品項，會跳出警示並請使用者重新輸入。
* **自動計算**：即時將點選的品項記錄至購物車並累加總金額。

## 🚀 使用說明

1. **執行程式**：
   在終端機（Terminal）執行以下指令：
   ```bash
   python 販賣機.py
點餐流程：

程式將印出完整菜單。

依提示輸入想要購買的餐點名稱（如：可樂）。

若要結束點餐，請直接按下空白鍵後按下 Enter。

結束後系統將印出最終應付總金額。

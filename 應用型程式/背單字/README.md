# 英文單字測驗程式 (English Vocabulary Quiz)

一個基於 Python 開發的命令列（CLI）英文單字測驗工具。程式會從內建的單字庫中隨機抽題，讓使用者透過中文意思輸入對應的英文單字，測驗結束後會自動計算總分並給予相對應評語。

---

## 🌟 功能特點

- **隨機抽題機制**：每次執行皆隨機從單字庫中選取 10 個單字進行測驗，重複性低。
- **不分大小寫比對**：答案比對自動忽略大小寫（如 `Apple` 與 `apple` 皆算答對）。
- **容錯輸入處理**：自動去除使用者輸入答案時前後不小心輸入的空白（`.strip()`）。
- **即時回饋**：每題答完後立即顯示對錯，若答錯會顯示正確答案。
- **自動計分與評語**：測驗結束後顯示總分（滿分 100 分），並依據分數給予不同鼓勵語。

---

## 🛠️ 環境需求

- **Python** 3.6 或以上版本
- 無需安裝額外的第三方套件（僅使用 Python 原生標準庫 `random`）

---

## 🚀 使用說明

### 1. 執行程式

在終端機（Terminal / Command Prompt）中切換至程式所在目錄，執行以下指令：

```bash
python 背單字.py
```

### 2. 進行測驗

程式啟動後會顯示題目說明與題目：

```text
=== 英文單字測驗 ===
共 10 題，每題 10 分

第 1 題
蘋果 的英文是：apple
答對了！

第 2 題
選修科目 的英文是：option
答對了！
...
```

### 3. 查看結果

答完 10 題後，系統會顯示最終得分與結語：

```text
=== 測驗結束 ===
你的總分：100 分
滿 分 ！ 太 厲 害 了 ！
```

---

## 📝 擴充與自訂單字庫

你可以輕鬆新增或修改 `words` 字典中的單字資料。格式為 `"英文單字": "中文解釋"`：

```python
words = {
    "conclusion": "結束",
    "conclude": "做結論",
    # 在此新增你的單字...
    "python": "蟒蛇 / 一種程式語言",
}
```

## 📊 計分標準

| 分數範圍 | 評語 |
| :--- | :--- |
| **100 分** | 滿 分 ！ 太 厲 害 了 ！ |
| **80 ~ 90 分** | 差 一 點 就 滿 分 了 ! ! ! |
| **60 ~ 70 分** | 不 錯 喔 ， 繼 續 加 油 ！ ! ! |
| **0 ~ 50 分** | You failed ，要 多 背 幾 次 單 字 喔 ！ ! ! |

# 雙電腦猜拳對決 (Dual Computer Rock-Paper-Scissors)

一個簡單的 Python 命令列遊戲，模擬兩台電腦自動進行剪刀、石頭、布對決，並透過互動式問答決定是否繼續下一輪。

## 核心功能

* **隨機出牌**：使用 `random.choice()` 隨機決定兩台電腦的出拳結果。
* **勝負判定**：包含平手與兩方獲勝邏輯。
* **遊戲迴圈**：輸入 `y` 繼續，其他鍵結束。

## 使用說明

### 執行步驟
1. 執行程式：
   ```bash
   python 剪刀石頭布.py
   ```
2. 觀察出拳結果，當提示 `Play another round?` 時輸入 `y` 繼續或按其他鍵結束。

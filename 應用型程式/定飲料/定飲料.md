簡易餐點點餐與結帳系統 (Menu & POS System)這是一個基於 Python 物件導向程式設計 (OOP) 所實作的點餐與結帳終端機應用程式。使用者可以瀏覽菜單、將餐點加入購物車，並選擇「刷卡」或「付現」進行結帳計算。📌 功能特色 (Features)物件導向設計 (OOP)：Food 基底類別：定義商品名稱 (name) 與價格 (price) 屬性，並提供展示資訊方法 show_info()。Drink 與 Snack 繼承類別：繼承自 Food，分類管理飲料與點心項目。菜單展示：自動遍歷與顯示所有可用餐點及價格。動態點餐購物車：支援連續輸入商品名稱加入購物車。自動檢查商品是否存在，若不存在會進行提示。按下 Enter 鍵即可完成選購並進入結帳流程。多元結帳與找零計算：刷卡 (Credit Card)：自動模擬刷卡成功流程。付現 (Cash)：輸入實付金額，自動計算應找零錢或顯示金額不足提示。🛠️ 程式架構 (System Architecture)程式碼片段classDiagram
    class Food {
        +str name
        +int price
        +show_info()
    }
    class Drink {
        +category() "飲料"
    }
    class Snack {
        +category() "點心"
    }

    Food <|-- Drink
    Food <|-- Snack

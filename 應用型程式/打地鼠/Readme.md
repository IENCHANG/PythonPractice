# 無限打地鼠 (Whack-a-Mole)

一個使用 Python 編寫的簡單文字版「無限打地鼠」終端機遊戲。

## 🎮 遊戲簡介

遊戲採取回合制：

* 每回合系統會隨機決定地鼠是否出現。
* 地鼠出現時，你可以選擇是否進行打地鼠行動。
* 打地鼠有 50% 的機率成功命中得分。
* 隨時輸入空白鍵即可結束遊戲並結算最終得分。

---

## 🚀 快速開始

### 環境要求

* **Python 3.x**（內建 `random` 模組，無須額外安裝第三方庫）

### 執行方式

直接使用 Python 執行主程式檔案：

```bash
python main.py

```

---

## 🕹️ 遊戲操作說明

* **地鼠出現時**：
* 輸入 `y` 或 `Y`：嘗試揮棒打地鼠（50% 機率命中 +1 分）。
* 直接按下 `Enter`：不動作，地鼠會鑽回地底。
* 輸入 `空格 (Space)`：離開遊戲。


* **沒有地鼠時**：
* 直接按下 `Enter`：繼續下一回合。
* 輸入 `空格 (Space)`：離開遊戲。



---

## 🏗️ 程式架構說明

* `Gopher` 類別：管理地鼠狀態（顯示/隱藏）與動作（跳起/鑽下）。
* `Person` 類別：管理玩家打地鼠行為與命中判定邏輯。
* 主迴圈 (`while`)：控制遊戲流程、接收玩家輸入與結算分數。

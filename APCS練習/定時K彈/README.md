# 💣 定時 K 彈 (The K-Bomb Josephus Problem)

> **「大家手拉手圍成一圈，數到 M 的幸運兒... 恭喜淘汰出場！」** 💥

歡迎來到 **定時 K 彈** 解題專案！這是一個經典的 **約瑟夫環問題 (Josephus Problem)** 變型實作。用 Python 模擬淘汰環，看看誰能笑到最後，成為最終的生存者 (Winner)！

---

## 📜 題目梗概 (Story)

有 $N$ 個人圍成一個大圈圈，編號分別為 $1$ 到 $N$。
大家開始玩報數遊戲，從當前位置開始往後數到第 $M$ 個人：
1. **傳彈報數**：每次數到第 $M$ 個人，炸彈就會爆炸！該名幸運兒直接淘汰出場 💥。
2. **繼續下一輪**：由下一位玩家繼續從 $1$ 開始報數。
3. **終極倖存者**：不斷重複這個淘汰過程，直到最後只剩下 $1$ 個人！

---

## 💡 解題亮點 (Highlights)

* 🔄 **取模運算 (`%`) 的魔法**：利用 `(idx + M - 1) % len(a)` 輕鬆實現環狀結構的索引計算，不需要真的去維護一個雙向鏈結串列！
* 🗑️ **動態縮減陣列 (`pop`)**：使用 Python 列表內建的 `.pop(idx)`，精準剔除被淘汰的玩家並自動接續下一位。
* 📝 **保留演算法進化痕跡**：註解中留下了最初嘗試的模擬思維，展現了從簡單迴圈探索到精準公式計算的思考歷程！

---

## 🛠️ 程式碼一覽 (Code)

```python
# N: 總人數, M: 報數間隔, K: 淘汰條件/次數限制
N, M, K = map(int, input().split())

# 初始化玩家列表 [1, 2, ..., N]
a = [i + 1 for i in range(N)]

idx = 0
last_eliminated = None

# 開始淘汰環，直到只剩最後一人
while len(a) > 1:
    idx = (idx + M - 1) % len(a)
    last_eliminated = a.pop(idx)

# 最終勝者
winner = a[0]
print(winner)
```

## 🔍 思考與優化亮點 (Notes & Optimization)

* ⚠️ **關於參數 $K$**：
  目前的實作程式碼將玩家淘汰至只剩 1 人（忽略了輸入中的 $K$）。若題意是 **「淘汰 $K$ 次後的當前報數者」** 或 **「剩下特定人數」**，可以將 `while len(a) > 1:` 修改為依據 $K$ 的次數控制喔！
* ⚡ **時間複雜度小提醒**：
  使用 `list.pop(idx)` 的時間複雜度為 $O(N)$，總體時間複雜度為 $O(N^2)$。對於一般的 $N$ 已經非常快速；若 $N$ 極大（如 $10^5$ 以上），可以考慮用 **遞迴/動態規劃** 的數學公式 $O(N)$ 來解，或是使用 `collections.deque` 哦！
